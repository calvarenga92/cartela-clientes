# Cartela Clientes

Cartela fidelidade digital para salões de beleza: cadastro de clientes, carimbo a cada visita e prêmio a cada 10 carimbos.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS
- Supabase (Postgres, Auth, Row Level Security)
- Deploy: Vercel

## Status

Em planejamento — MVP (Fase 1).
